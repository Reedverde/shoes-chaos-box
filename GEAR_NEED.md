# Gear Need

The original electronics order has arrived and passed basic operation. There
are no missing core electronic modules.

The active, intentionally short procurement list is maintained in
[PURCHASE_LIST.md](PURCHASE_LIST.md). Remaining needs are connectors, flexible
wire if not already owned, insulation/strain relief, lapel mounting hardware,
and a shallow nonconductive pocket carrier.

Do not buy capacitors, another controller, another display, another battery,
perfboard, or a combined 12-pin connector unless later testing creates a
specific need.
